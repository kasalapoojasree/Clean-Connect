# Real waste-image dataset

CleanConnect uses the public **TrashNet** image dataset for its real supervised ML model.

Classes:
- cardboard -> Cardboard
- glass -> Glass
- metal -> Metal
- paper -> Paper
- plastic -> Plastic
- trash -> Mixed Waste

The training script downloads the resized 42.8 MB archive automatically. The dataset contains 2,527 labelled images in the original resized release.

Source: Gary Thung / Mindy Yang, Stanford CS229 TrashNet.

Do not add generated/fixed example data and call it training data. For the college project, keep the dataset source and the generated `training_report.txt` with the project.
