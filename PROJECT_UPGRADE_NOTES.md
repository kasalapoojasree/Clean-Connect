# CleanConnect upgrade notes

This upgrade preserves the existing pages and workflows and adds supporting ML observability and project-quality improvements.

## Added
- Top-3 class ranking in the ML inference response.
- Low-score review flag (below 55%) to encourage manual confirmation.
- Balanced accuracy, macro-F1 and training timestamp in the model bundle.
- JSON model card, classification report and confusion matrix generated at training time.
- Admin-only ML Insights page at `/admin/ml-insights`.
- `/api/health` database/model readiness endpoint.
- Smoke tests in `tests/test_smoke.py`.
- Random first-run admin password instead of a predictable hard-coded password.
- `.env.example` and `.gitignore` to reduce accidental secret/data commits.
- Debug mode defaults off.

## Rebuild and verify on your computer
1. Open a terminal in `CleanConnect`.
2. Create/activate a virtual environment and install `requirements.txt`.
3. Run `python train_model.py` and review the printed hold-out metrics.
4. Run `python -m unittest discover -s tests -v`.
5. Run `python app.py` and check `/api/health`.
6. Sign in as admin and open `/admin/ml-insights`.
7. Manually test registration, login/logout, report creation, image classification, complaint status history, volunteer registration, filters, maps, analytics, and demo-data removal.

## Known limits (be transparent in a resume or viva)
- The Random Forest is trained from engineered RGB/HSV histograms and simple edge statistics; it is a classical ML baseline, not a deep neural network.
- TrashNet is a small benchmark and may not represent all local waste, lighting, camera, and background conditions.
- Random Forest `predict_proba` values are model scores and are not calibrated confidence estimates.
- The 55% review flag is a heuristic policy threshold, not a validated operating point.
- A live model artifact is generated by `python train_model.py` and is intentionally not included in source control/ZIP by default.
- The smoke suite needs dependencies from `requirements.txt`; external dependencies could not be installed in the packaging environment if the network is unavailable.
